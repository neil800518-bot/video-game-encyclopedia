# Video Game Encyclopedia

电子游戏百科全书 — 电子游戏资料管理与图片辨识搜寻系统。

## Project Features

- Game database management
- Game image recognition and search
- Search by game name and provider
- Support for multiple game providers
- Web-based game encyclopedia
