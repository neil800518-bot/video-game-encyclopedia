# v3 Phase 13 | 多樣本結構映射穩定性驗證（唯讀）

## 目的
延續 Phase 12，使用多張具已知正確遊戲 ID 的查詢截圖，驗證結構負相關處理方式是否改善辨識；不得以單張截圖或單次名次翻轉宣稱準確率提升。

## 基準與方案
- C 原始截斷：max(0, raw_correlation)
- 負相關映射至 0–1：(raw_correlation + 1) / 2
- 保留負相關貢獻：raw_correlation
- 沿用 Phase 12 C 權重：結構 25%、雜湊 25%、色彩 50%，保留原候選區域與面積扣分。
- 所有方案使用相同查詢樣本、相同索引快照與相同候選區域，逐張獨立重排全索引。

## 驗證資料
- 每張測試截圖需附正確遊戲 ID、樣本識別碼、來源與是否可公開展示。
- 先檢查標註是否正確、是否有重複或近重複樣本；不得將同一張圖的裁切版本當成獨立遊戲樣本。
- 先以 CG-0001、DB-0041 及其他不同廠商/版型遊戲構成測試集合；樣本數由實際取得的有標註截圖決定，不虛報覆蓋率。
- 記錄索引圖片數、查詢尺寸、樣本數、無法評分/缺少正確 ID 的樣本。

## 輸出
1. 每樣本 × 每方案：正確 ID 排名、正確 ID 分數、Top 1 ID/分數、Top 3 ID、Top 1 與正確 ID 分差、最佳區域、負相關區域數。
2. 彙總：Top 1、Top 3 命中數及命中率、平均/中位正確 ID 排名、平均名次變化、勝負平局樣本數。
3. 分層：依遊戲 ID/廠商、畫面方向、查詢類型展示，僅在有足夠樣本時解讀。
4. 基準一致性：固定同一查詢與索引，比對 Phase 11 最佳區域 C 分數與 Phase 12 原始截斷分數；如不一致，記錄候選區域、特徵、面積扣分與計算路徑，不直接歸因浮點誤差。
5. 顯示每項指標的分母、缺失值、排序 tie-break 規則；保留原始逐樣本結果供重現。

## 驗收與限制
- 不修改 similarity()、rank_image_matches()、正式搜尋結果、資料庫、索引圖片與 main 分支。
- 診斷 UI 與正式搜尋隔離，預設不影響既有使用流程。
- 無標註樣本不能計入準確率；多樣本結果未完成前不得宣稱任何方案較佳。
- 先以測試網站審核，經確認後才考慮合併。
