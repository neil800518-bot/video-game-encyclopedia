# Phase 14｜图片辨识 Top 1 改善（开发计划）

## 目标
以「游戏图片总览」的现有资料库图片为基准，提高上传游戏截图后正确游戏位居第 1 名的比例。此阶段不更改正式搜寻结果、游戏 ID、厂商、游戏名称或资料库图片。

## 执行顺序
1. 检查现有图片索引、预处理、裁切、特征与排序流程，记录当前 Top 1 排名与分数。
2. 以资料库中可确认对应游戏 ID 的图片进行回归测试；测试图可由现有图片衍生为缩放、压缩、边框、裁切等版本，不要求用户提供 CSV。
3. 分别验证原图与轻度画面变形下的辨识表现，统计 Top 1 / Top 3 命中率与误认案例；不将资料库原图自我比对结果当成真实截图准确率。
4. 先做候选图片预处理和特征改善；每项变更保留旧版对照与回退方式。
5. 仅在证据显示改善、且不破坏现有功能时，提出实际算法变更供审查。

## 安全边界
- 不在此规划提交中修改 similarity()、rank_image_matches()、app.py 正式排序或 data/。
- 不改变名称 / ID 搜寻、图片总览、图片上传、贴图、清除图片及前 3 / 前 5 切换。
- 不保证所有截图都能准确列为第 1 名；须以实际测试结果决定是否上线。
- 此分支的 PR 维持 Draft，验证通过后再考虑合并。

## 下一阶段（Phase 15）
新增按固定游戏 ID 上传更清晰资料库图片的后台管理功能：上传前预览、格式/尺寸检查、保留旧图备份、替换后重建索引、可回滚。另开分支与 PR，不与 Phase 14 混合。
