## 現況與統計（原版清單 + 使用者最新修訂）
- 原版 Excel (5) PP 記錄：610 筆；main PP 記錄：324 筆（50 筆已有圖片），新增來源位置 286 筆。新版 Excel (6) **是否仍為 610 筆待檔案機器解析核實**。
- 修訂後，舊版 324 筆的候選核對預計為：**318 筆名稱唯一且相符、3 筆舊遊戲落在同名雙圖候選、3 筆新版名稱已由使用者確認（與 main 舊寫法不同）**。
- PP-0051～PP-0324 的舊固定 ID 存在變動風險，不得直接以新編號覆蓋 main，亦不得把不同遊戲的圖片覆蓋。
